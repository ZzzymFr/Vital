一个 Decoder 块的内部

先定义 H 为本块输入，U 为第一次残差后的结果；二者均为 [B,T,512]。两条左侧支路保存未归一化的残差。

输入 H → LayerNorm₁
因果多头自注意力（内含 RoPE）
Dropout（可选）
U = H + 注意力输出
U → LayerNorm₂
前馈网络：512 → 2048 → 512
Dropout（可选）
Hnext = U + 前馈输出
U = H + Dropout(Attention(LN₁(H)))
Hnext = U + Dropout(FFN(LN₂(U)))

Attention 在位置之间混合信息；FFN 对每个位置单独做特征变换。两者都保持输出宽度 512，才能与残差相加。

前馈网络也有明确边界

Z 表示归一化后的输入，W₁、W₂ 是可训练矩阵，b₁、b₂ 是偏置。

FFN(Z) = SiLU(Z W₁ + b₁) W₂ + b₂
W₁: [512,2048] · W₂: [2048,512]

当前 FNN 内置 LayerNorm，且第二个线性层后也有 SiLU。本页基线把归一化放在块里、只在两层之间保留 SiLU。不要在照图实现时无意叠加归一化；现有双 SiLU 是另一种变体，并不等于 SwiGLU。

为什么单靠当前前馈网络还不够？ 当前网络逐位置计算，最后的 <assistant> 向量接收不到前文信息。接入自注意力后，该位置才能根据前面不同的请求，形成不同的上下文表示。能够传递上下文不等于已经学会任务，还需要训练与独立评估。
02 / ROPE 旋转位置编码

让位置通过旋转，进入注意力分数

这一版采用你选择的 RoPE：词元嵌入直接进入 Decoder；每层 Attention 先投影和拆头，再用正弦／余弦旋转 Q、K，随后计算点积。位置决定旋转角度，内容决定被旋转的向量。

dₕ每头 64 维，共 32 对
r维度对编号，0…31
θᵣ第 r 对的固定角频率
p / s查询 / 键的绝对位置
qₚ / kₛ旋转前的一个头内向量
q̃ₚ / k̃ₛ旋转后的同维度向量

① 每两维，构成一个旋转平面

本页采用相邻配对：[0,1]、[2,3]、…、[62,63]。令 u=[a,b]ᵀ 为 Q 或 K 的一对分量，t 为其位置，α=tθᵣ 为旋转角。

θᵣ = 10000−2r/64
α = t · θᵣ

a′ = a cos(α) − b sin(α)
b′ = a sin(α) + b cos(α)

R(α) = [[cos α, −sin α],
　　　　[sin α,　cos α]]

Q 按查询位置 p 旋转，K 按键位置 s 旋转；V 保持原样。旋转保留向量长度，改变方向。频率使用每头维度 64，而不是总隐藏维度 512。

位置编号和频率都是输入或固定配置。基础 RoPE 不新增可训练参数；WQ、WK、WV、WO 仍然通过训练更新。基数 10000 是本页采用的基础配置，并非所有模型都固定使用该值。

② 在每层 Attention 内插入

  1. 归一化 → Q/K/V 投影 → 拆头
    Q, K, V: [B,8,T,64]

    每层从自己当前的隐藏表示生成 Q/K/V。

  2. RoPE：仅旋转 Q、K 待实现
    position_ids: [B,T]
    角度、sin、cos: [B,1,T,32]
    Q̃, K̃: [B,8,T,64]

    32 对分量分别旋转；角度广播到 8 个头。

  3. 旋转后点积 → 遮罩 → 权重
    A = softmax(Q̃K̃ᵀ / √64 + M)

    然后用 A 汇聚原本的 V，合头、输出投影，再进入残差支路。位置影响读取权重，从而影响上下文输出。

这里不是先计算一个 512 维位置向量再相加。RoPE 计算每个位置的旋转系数，并将它们作用于 Q/K。注意力依然是缩放点积；用了 cos 旋转，不等于使用“余弦相似度注意力”。因果遮罩仍然需要，RoPE 不会自动阻止读取未来。

图中显示一对分量的点积贡献。真实每头分数需要将 32 对的贡献求和，再除以 √64=8；随后才应用遮罩和 softmax。这不是已经归一化的注意力权重。

为什么绝对位置旋转，会产生相对位置项？

令 qₚ⁽ʳ⁾、kₛ⁽ʳ⁾ 为完整单头向量中第 r 对二维分量，按列向量书写；R 是 2×2 旋转矩阵。先分别旋转：

q̃ₚ⁽ʳ⁾ = R(pθᵣ) qₚ⁽ʳ⁾，k̃ₛ⁽ʳ⁾ = R(sθᵣ) kₛ⁽ʳ⁾
(q̃ₚ⁽ʳ⁾)ᵀk̃ₛ⁽ʳ⁾ = (qₚ⁽ʳ⁾)ᵀ R(pθᵣ)ᵀ R(sθᵣ) kₛ⁽ʳ⁾
　　　　　　　　= (qₚ⁽ʳ⁾)ᵀ R((s−p)θᵣ) kₛ⁽ʳ⁾

旋转项只依赖 s−p。保持原始 q、k 不变，把两个位置同时增加 c，点积不变。完整 64 维情形是 32 个二维结果相加。真实分数还依赖内容向量，不保证距离越近分数越大，也不保证整套模型对任意输入平移都完全不变。

要实现的 RoPE 模块：相邻维度配对版本

q、k 均为 [B,h,T,dₕ]；position_ids 为同设备的整数张量 [B,T]。此接口对新投影的 Q/K 旋转一次；之后由 Attention 做点积。函数返回两个旋转结果，不接收也不修改 V。

class RotaryPositionEncoding(nn.Module):
    def __init__(self, head_dim=64, base=10000.0):
        super().__init__()
        if head_dim <= 0 or head_dim % 2 or base <= 0:
            raise ValueError("每头维度必须为正偶数，基数必须为正数")
        self.head_dim = head_dim
        inv_freq = base ** (-torch.arange(0, head_dim, 2, dtype=torch.float32) / head_dim)
        self.register_buffer("inv_freq", inv_freq)

    def forward(self, q, k, position_ids):
        if q.ndim != 4 or q.shape != k.shape or q.size(-1) != self.head_dim:
            raise ValueError("q、k 必须同形且为 [B,h,T,head_dim]")
        B, _, T, _ = q.shape
        if position_ids.shape != (B, T):
            raise ValueError("position_ids 必须为 [B,T]")
        # position_ids 非负、同设备；inv_freq 保持 float32
        angles = position_ids.float()[..., None] * self.inv_freq.float()
        cos = angles.cos()[:, None, :, :]  # [B,1,T,head_dim/2]
        sin = angles.sin()[:, None, :, :]

        def rotate(x):
            a, b = x[..., 0::2], x[..., 1::2]
            c, s = cos.to(x.dtype), sin.to(x.dtype)
            out_a = a * c - b * s
            out_b = a * s + b * c
            return torch.stack((out_a, out_b), dim=-1).flatten(-2)

        return rotate(q), rotate(k)

混合精度时保留 float32 频率与角度计算。此处只展示相邻配对；另一类实现采用前后半维配对，需与其频率展开及权重布局一致，不能任意混用。无缓存右填充基线用 arange(T) 在 B 维扩展生成 position_ids。

生成与 KV 缓存的两个位置细节

  • 无缓存：每次把完整前缀送入模型，position_ids 从 0 到 T−1，所有层使用一致的位置编号。
  • 有缓存：新词元的位置继续从已有有效前缀长度开始。先旋转新 Q/K，再把旋转后的新 K 与原 V 追加到缓存；不能把每个新词元都当位置 0，也不能再次旋转旧缓存 K。
  • 长度与填充：Tmax 是配置上限；RoPE 公式可计算更远的位置，但长上下文效果仍需验证。若改成左填充或不同有效长度的缓存批次，应逐样本追踪真实位置，不能直接拿补齐宽度当所有样本的位置。
03 / ATTENTION 拆解

Attention 的输入和输出都是一串向量

本节令 X = LN₁(H)，形状为 [B,T,512]；第一块的 X 来自词元嵌入；位置编号在每层投影拆头后用于 RoPE，后续层的隐藏状态也会承载前层形成的上下文与位置信息。V 专指 Value 张量，词表大小用 N 表示。

Q · 查询

当前位置用什么特征寻找相关上下文？由 X 经 WQ 投影得到。

K · 键

各个位置提供什么特征供查询匹配？由 X 经 WK 投影得到。

V · 值

匹配之后，实际读取并加权汇总哪些内容？由 X 经 WV 投影得到。

核心公式：对每一批次、每一个头，A = softmax((Q̃K̃ᵀ / √dₕ) + M, dim=-1)，C = A V。Q̃、K̃ 表示经 RoPE 旋转后的 Q、K，V 不旋转。M 为加性遮罩，允许的位置为 0，禁止的位置为 −∞。Q、K、V 是本次前向计算的激活张量；WQ、WK、WV、WO 才是训练时更新的参数。

形状总账：不要把“头”与“层”混为一谈

阶段张量形状轴的含义 / 实现要求
输入 X[B,T,512]批次、位置、隐藏特征
投影后的 Q、K、V各 [B,T,512]三个独立线性变换；也可合并成一次 512→1536 投影再切分
拆头后的 Q、K、V各 [B,8,T,64]先 reshape 成 [B,T,8,64]，再交换 T 与头维度
RoPE 后的 Q̃、K̃各 [B,8,T,64]每头 32 对相邻特征按位置旋转；V 保持原样；频率分母使用每头维度 64
分数 S 与权重 A[B,8,T,T]倒数第二轴是查询位置 i；最后轴是被读取的位置 j
每头汇聚 C = AV[B,8,T,64]每头仍为每个位置产生 64 维向量
合头 Ccat[B,T,512]transpose 回 [B,T,8,64] 后再 reshape，不能直接混并原轴
输出 O[B,T,512]经 WO 投影；交给块外的 Dropout 与残差加法

8 个头在同一层内并行计算；6 个块沿深度依次计算。不能把 8 个头当作连续调用同一 Attention 8 次。标准显式注意力矩阵的存储量随 T² 增长。

直接对应到要写的 Attention.forward

下面是实现参考，未写入模型。前提：每条序列非空且只在右侧补 PAD；x 已由 Decoder 块归一化；valid 是同一序列的非 PAD 布尔矩阵 [B,T]。q_proj/k_proj/v_proj/out_proj 均为 512→512 线性层，attn_dropout 为 nn.Dropout，self.rope = RotaryPositionEncoding(64)，对应模块见“RoPE 位置机制”页。position_ids 为同设备的非负整数位置编号 [B,T]；当前右填充方案的有效位置从 0 开始。

def forward(self, x, valid, position_ids):
    B, T, d = x.shape
    h, dh = 8, 64
    # 调用前校验：d == h * dh；valid.shape == (B, T)
    # 当前基线要求每条样本首位非 PAD，后面只允许右侧补齐。
    q = self.q_proj(x).reshape(B, T, h, dh).transpose(1, 2)
    k = self.k_proj(x).reshape(B, T, h, dh).transpose(1, 2)
    v = self.v_proj(x).reshape(B, T, h, dh).transpose(1, 2)

    q, k = self.rope(q, k, position_ids)  # 投影拆头后旋转，v 不变
    scores = (q @ k.transpose(-2, -1)) / (dh ** 0.5)
    causal = torch.ones(T, T, dtype=torch.bool, device=x.device).tril()
    allowed = causal[None, None, :, :] & valid[:, None, None, :]
    scores = scores.masked_fill(~allowed, float('-inf'))
    weights = torch.softmax(scores.float(), dim=-1).to(v.dtype)
    context = self.attn_dropout(weights) @ v

    merged = context.transpose(1, 2).contiguous().reshape(B, T, d)
    out = self.out_proj(merged)
    # 丢弃 PAD 查询位置的结果；有效查询始终至少能看见首位 BOS。
    return out.masked_fill(~valid[:, :, None], 0)

这个普通实现会显式生成 [B,h,T,T]。先用它核对公式，再考虑融合算子；混合精度时还应检查分数有限性。若支持左填充或全 PAD，必须另行处理全遮罩行，不能对整行 −∞ 直接做普通 softmax。

用 PyTorch 融合注意力替换中间计算时

scaled_dot_product_attention 可接收拆头并已完成 RoPE 的 q、k，以及未旋转的 v；该融合函数本身不替你执行 RoPE。无 PAD 的方形全序列可用 is_causal=True；有 PAD 时显式合并因果与填充条件，传 attn_mask=allowed, is_causal=False。该函数的布尔遮罩中 True 表示允许，与 MultiheadAttention.key_padding_mask 的 True 表示屏蔽相反。评估时明确传 dropout_p=0.0。官方接口说明 ↗

05 / 训练与生成

同一个网络，两种使用方式

logits 是原始词表分数，概率才是对词表维度做 softmax 后的结果。注意力 softmax 则沿被读取的位置维度做归一化。

当前逐词元训练方式

教师强制：追加正确答案词元

BOS · 用户请求 · 助手标记→预测 a₁
前缀 · 正确 a₁→预测 a₂
前缀 · 正确 a₁ · 正确 a₂→预测 EOS
  1. 输入当前前缀，取最后一个非 PAD 位置的 logits，形状 [B,N]。
  2. 标签是剩余正确答案的第一个词元，形状 [B]、类型 long。
  3. 交叉熵接收原始 logits；忽略 PAD 标签，再反向传播、更新参数。
  4. 将正确标签追加到有效前缀末尾，继续预测下一词元。

当前 train.py 的每个 epoch 实际完成一次词元位置的更新，尚不是完整遍历全部回答的一轮常规 epoch。

当前贪心生成方式

自回归：追加自己预测的词元

BOS · 用户请求 · 助手标记→预测 â₁
前缀 · 预测 â₁→预测 â₂
前缀 · 预测 â₁ · 预测 â₂→继续 / EOS
  1. model.eval() 并关闭梯度，先输入请求前缀。
  2. 取最后有效位置分数 [B,N]；当前用 argmax，概率采样可后续添加。
  3. 把模型选出的编号追加回输入，不接入参考答案。
  4. 生成 EOS 或达到长度限制时停止，最后由 BPE 解码。

当前生成上限为 128 个新词元。采用 RoPE 后仍需遵守配置的上下文上限 Tmax；公式可以计算更远位置，但不保证训练长度之外的生成效果。

可后续改为并行全序列训练

一次前向，同时预测每个位置的下一词元

令 s 是一条完整序列，含提示词、正确回答和 EOS；a₁、a₂ 是正确回答词元。

完整序列 s = [BOS, …用户请求…, 助手标记, a₁, a₂, EOS]
单条输入 = s[:-1]　→　[T]；组批补齐后 [B,T]
单条目标 = s[1:]　 →　[T]；组批补齐后 [B,T]
logits = model(输入, last_token_only=False)　→　[B,T,N]

训练时因果遮罩阻止每个位置偷看后续答案；如果只监督助手回答，提示词对应的目标设为忽略值，但提示词仍然参与注意力。当前项目的忽略值使用 PAD 编号 256；也可另选 −100，但必须与损失函数一致。助手标记所在输入位置的目标是 a₁，应计入损失。

两个容易混淆的 softmax

Attention：[B,h,T,T] 沿最后一维，得到“读取哪些位置”的权重。

生成概率：[B,N] 沿 N 维，得到“下一个词元选谁”的分布。训练交叉熵内部处理归一化，不提前把 logits 转成概率。

最后位置要在上下文计算之后选

普通无缓存实现先让整段序列通过各个 Decoder 块，再选最后有效位置输出。不能先把输入裁成最后一个助手标记，否则即使写了 Attention，也看不到前文。KV 缓存是保留前文 K、V 后的增量计算方案。

最小正确性验收

  • 形状：输入 [2,5,512]，Attention 输出仍为 [2,5,512]；中间权重为 [2,8,5,5]。
  • 因果性：关闭 Dropout，修改位置 i 之后的词元，位置 0…i 的 logits 应保持一致（允许浮点误差）。
  • PAD 隔离：追加右侧 PAD，不应改变原有效位置的输出；用同一显式 valid 改变 PAD 位置的隐藏输入，也不应影响有效输出。
  • 上下文依赖：保持最后词元不变，替换前文，检查最后位置 logits 能否变化；检查前文嵌入是否有非零梯度路径。
  • RoPE：位置 0 旋转为恒等变换；旋转前后 Q/K 范数相同，V 不变。保持原始 Q/K 不变、把两者位置同步平移，点积应一致；缓存与全序列输出应等价。
  • 独立层：不同块的权重是不同 Parameter 对象，且都注册到模型与优化器。
  • 边界：单词元、长度不一的批次、T=Tmax、空输入、全 PAD 输入、EOS 停止都要有明确行为。

后续扩展，不是补全首版的前置要求

  • RoPE 扩展：本页已把基础 RoPE 纳入核心。改变频率基数、部分旋转或长上下文缩放都属于后续配置变体，需要单独验证。
  • KV 缓存：每层保存已旋转的 K 与未旋转的 V，形状 [B,h,Tpast,dₕ]。新词元按真实绝对位置旋转 Q/K，再追加 K/V；旧 K 不重复旋转。查询仍读取全部允许的历史键。
  • 缓存因果对齐：用真实绝对位置判断 key_pos ≤ query_pos；非方形增量注意力不能机械套用左上角三角遮罩。
  • 权重共享：可共享词元嵌入与输出矩阵；这是词表参数绑定，与复用同一个 Decoder 块不同。
  • 更高效的注意力：融合实现可减少中间矩阵的显存占用；先确认结果与普通公式一致。
  • RMSNorm / SwiGLU / GQA：是可选架构变体，不应与当前 LayerNorm、SiLU、普通多头方案混着当成已经实现。
