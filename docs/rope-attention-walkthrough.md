# RoPE 与多头自注意力：逐步讲解

**RoPE＋Attention 的作用是：让每个词元结合“内容匹配”和“位置关系”，决定从前面的词元中读取多少信息，最后得到一个新的 512 维向量。**

下面沿着你这版 **512 维、8 个头、每头 64 维、Pre-LN** 的方案走一遍。先讲完整序列的前向计算，不展开 KV 缓存。

先把变量固定下来：

| 符号 | 含义 | 本次示例 |
|---|---|---|
| \(B\) | 同时处理的序列数 | \(1\) |
| \(T\) | 每条序列的词元数 | \(4\) |
| \(d\) | 每个词元的隐藏维度 | \(512\) |
| \(h\) | 注意力头数 | \(8\) |
| \(d_h=d/h\) | 每个头的特征维度 | \(64\) |
| \(H\) | 当前 Decoder 块的输入 | \([1,4,512]\) |

假设四个位置是：

```text
位置：  0      1      2      3
词元： BOS     我     喜欢    数学
```

这只是教学用的词元划分，不代表实际 BPE 的切分结果。

1. **先归一化，为 Attention 准备输入**

   定义 \(X\) 为归一化后的隐藏状态：

   \[
   X=\operatorname{LayerNorm}(H)
   \]

   形状保持不变：

   \[
   [1,4,512]\longrightarrow[1,4,512]
   \]

   LayerNorm 分别处理每个词元自己的 512 个特征，**这一步还没有在不同词元之间交换信息**。

   同时保留原来的 \(H\)，后面用于残差相加。按照我们选的 Pre-LN 结构，这层归一化由 Decoder 块管理。

2. **从同一个 \(X\)，生成 Q、K、V**

   先定义三个可训练矩阵：

   \[
   W_Q,W_K,W_V\in\mathbb R^{512\times512}
   \]

   为了突出主要计算，以下省略偏置：

   \[
   Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V
   \]

   三个输出的形状都是：

   \[
   Q,K,V:[1,4,512]
   \]

   可以这样理解它们的分工：

   | 张量 | 作用 |
   |---|---|
   | \(Q\)：查询 | 当前词元用什么特征寻找相关内容 |
   | \(K\)：键 | 每个词元提供什么特征供查询匹配 |
   | \(V\)：值 | 匹配之后，实际读取和汇总的内容 |

   **每个词元都会产生自己的 Q、K、V。** 三个投影矩阵在不同词元位置之间共享，但 \(W_Q、W_K、W_V\) 各自学习。

3. **把 Q、K、V 拆成 8 个头**

   每次投影产生了 512 个特征，现在把它们分成 8 组，每组 64 维。

   先重新组织形状，再交换轴：

   \[
   [1,4,512]
   \rightarrow[1,4,8,64]
   \rightarrow[1,8,4,64]
   \]

   对应操作：

   ```python
   q = q.reshape(B, T, 8, 64).transpose(1, 2)
   k = k.reshape(B, T, 8, 64).transpose(1, 2)
   v = v.reshape(B, T, 8, 64).transpose(1, 2)
   ```

   现在四个轴分别是：

   ```text
   [序列编号, 注意力头编号, 词元位置, 头内特征]
   ```

   例如：

   ```python
   q[0, 3, 2, :]
   ```

   表示第 0 条序列、第 3 个头、位置 2“喜欢”的 **64 维查询向量**。

   每个头的投影都可以利用原始 512 维输入；拆头是对**投影后的特征**进行分组。

4. **用 RoPE 按位置旋转 Q、K**

   这是位置进入本层注意力计算的步骤。

   先定义：

   - \(p\)：某个词元的位置编号。
   - \(r=0,\ldots,31\)：一个头内的维度对编号。
   - \(\theta_r\)：第 \(r\) 对特征的固定角频率。
   - \(\alpha=p\theta_r\)：该位置、该维度对的旋转角度。

   本页采用：

   \[
   \theta_r=10000^{-2r/64}
   \]

   一个头的 64 个特征按相邻两维配对：

   ```text
   (第0维, 第1维)
   (第2维, 第3维)
   …
   (第62维, 第63维)
   ```

   对任意一对原始分量 \((a_0,a_1)\)，旋转后的分量为：

   \[
   \begin{aligned}
   a'_0&=a_0\cos\alpha-a_1\sin\alpha\\
   a'_1&=a_0\sin\alpha+a_1\cos\alpha
   \end{aligned}
   \]

   例如，位置 \(p=2\)、第一对特征 \(r=0\)，则：

   \[
   \theta_0=1,\qquad\alpha=2
   \]

   如果这对分量原本是 \((1,0)\)，旋转后就是：

   \[
   (\cos2,\sin2)\approx(-0.416,\ 0.909)
   \]

   **Q、K 都按各自词元的位置旋转，V 不旋转。** 记旋转结果为 \(\widetilde Q、\widetilde K\)，形状仍是：

   \[
   \widetilde Q,\widetilde K:[1,8,4,64]
   \]

   RoPE 改变向量方向、保持长度，并使 Q/K 点积中的旋转部分体现相对位置关系。[RoFormer §3.2](https://arxiv.org/html/2104.09864v5#S3.SS2)

5. **计算每个查询与所有键的匹配分数**

   定义 \(S\) 为缩放后的注意力分数：

   \[
   S=\frac{\widetilde Q\widetilde K^\top}{\sqrt{64}}
   =\frac{\widetilde Q\widetilde K^\top}{8}
   \]

   这里的转置只交换 K 的最后两个轴：

   \[
   [1,8,4,64]\times[1,8,64,4]
   \rightarrow[1,8,4,4]
   \]

   最后的两个“4”含义不同：

   ```text
   倒数第二轴：谁在查询
   最后一个轴：读取谁
   ```

   例如：

   ```python
   scores[0, 0, 2, 1]
   ```

   是第 0 个头里，位置 2“喜欢”对位置 1“我”的匹配分数。

   除以 \(\sqrt{64}\) 是为了控制点积的尺度，避免分数过大时 softmax 过于集中。[缩放点积注意力](https://arxiv.org/html/1706.03762v7#S3.SS2)

6. **应用因果遮罩和 PAD 遮罩**

   定义 \(M\) 为加到分数上的遮罩。允许读取的位置取 \(0\)，禁止的位置取 \(-\infty\)。

   对四个位置，因果遮罩是：

   \[
   M=
   \begin{bmatrix}
   0&-\infty&-\infty&-\infty\\
   0&0&-\infty&-\infty\\
   0&0&0&-\infty\\
   0&0&0&0
   \end{bmatrix}
   \]

   行是查询位置，列是被读取位置。

   因此，位置 2“喜欢”可以读取：

   ```text
   BOS、我、喜欢
   ```

   不能读取未来位置 3“数学”。

   **自身可以读取，因为位置 2 的输出用于预测位置 3 的词元。**

   如果序列中有 PAD，还要屏蔽 PAD 对应的键。RoPE 与遮罩承担不同职责：前者提供位置关系，后者限制允许读取的内容。

7. **沿“被读取的位置”做 softmax**

   定义 \(A\) 为注意力权重：

   \[
   A=\operatorname{softmax}(S+M,\ \mathrm{dim}=-1)
   \]

   形状仍是：

   \[
   A:[1,8,4,4]
   \]

   举一个独立的数值示例：假设某个头在位置 2 的分数为：

   \[
   [1,\ 2,\ 0,\ 3]
   \]

   遮罩未来位置后：

   \[
   [1,\ 2,\ 0,\ -\infty]
   \]

   softmax 得到：

   \[
   [0.245,\ 0.665,\ 0.090,\ 0]
   \]

   含义是：这个查询对前三个位置分别分配约 \(24.5\%\)、\(66.5\%\)、\(9.0\%\) 的读取权重，未来位置为零。

   **这里的概率分布是“读取哪些位置”，不是“下一个词元选谁”。**

   训练时可以在权重上使用 Dropout；使用后，单次计算的行和不一定仍为 1。下面为便于理解，继续按不使用 Dropout 讨论。[PyTorch 对应计算](https://docs.pytorch.org/docs/2.14/generated/torch.nn.functional.scaled_dot_product_attention.html)

8. **用权重加权汇总 V，真正读取上下文**

   定义 \(C\) 为每个头汇聚后的结果：

   \[
   C=AV
   \]

   形状变化：

   \[
   [1,8,4,4]\times[1,8,4,64]
   \rightarrow[1,8,4,64]
   \]

   延续上一例，令 \(v_0,v_1,v_2,v_3\in\mathbb R^{64}\) 是这个头里四个位置的 Value 向量，那么位置 2 的输出为：

   \[
   c_2=0.245v_0+0.665v_1+0.090v_2+0v_3
   \]

   结果 \(c_2\) 仍然是 64 维，但它已经汇集了多个位置的内容。

   **这是跨词元信息真正进入当前位置表示的一步。** Q、K 决定权重，V 提供被汇总的内容。

9. **合并 8 个头，再做输出投影**

   先将轴换回来，再拼接同一位置的 8 份结果：

   \[
   [1,8,4,64]
   \rightarrow[1,4,8,64]
   \rightarrow[1,4,512]
   \]

   ```python
   merged = context.transpose(1, 2).contiguous().reshape(B, T, 512)
   ```

   定义 \(W_O\in\mathbb R^{512\times512}\) 为可训练的输出投影矩阵，\(O\) 为 Attention 的最终输出：

   \[
   O=\operatorname{merged}W_O
   \]

   \[
   O:[1,4,512]
   \]

   这个投影让不同头提供的特征进一步混合。**它输出的是隐藏向量，还不是词表上的预测分数。**

10. **返回 Decoder 块，接上残差**

    定义 \(U\) 为注意力残差后的隐藏状态：

    \[
    U=H+\operatorname{Dropout}(O)
    \]

    两边的形状相同：

    \[
    [1,4,512]+[1,4,512]\rightarrow[1,4,512]
    \]

    注意加回的是最初保存的 \(H\)。

    **Attention 模块本身在输出 \(O\) 时已经完成；残差加法属于 Decoder 外层组合。** 接下来 Decoder 还会让 \(U\) 经过第二次归一化、前馈网络和第二条残差，再交给下一层。

    位置影响已经通过注意力权重进入上下文表示，所以这里不需要移除位置，也不需要反向旋转 Q、K。
